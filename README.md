# 帆船空气动力 VPP 模拟器

把“船速查一张表”的老式做法替换为**按空气动力学实时解算**的帆船竞速模拟器。
纯 TypeScript + Canvas 2D，无重型依赖；物理单帧 P95 < 0.02 ms（约束 < 1 ms），
五种级别帆船对设计参考极曲线的平均误差全部 < 8%。

## 物理模型

| 模块 | 文件 | 做法 |
| --- | --- | --- |
| 真风/视风 | `src/physics/wind.ts` | 风三角矢量变换 `V_app = V_true − V_boat`，船速上来视风自动前移、风速增大 |
| 帆空气动力 | `src/physics/sail-coefs.ts` | 升力/阻力系数 Cl(α)、Cd(α) 查表+线性插值，含失速段与深顺风球帆特性混合 |
| 帆力解算 | `src/physics/aero-hydro.ts` | 主帆/前帆独立收放与调帆角，攻角=视风角−调帆角，升阻→推力/侧力分解 |
| 横倾 | 同上 | 求根解 `HM(φ)=RM(φ)`，`RM=Δ·GZ·sinφ`；横倾降低帆效率，超过最大可持续角触发松帆泄力 |
| 侧滑 | 同上 | 龙骨侧向升力平衡气动侧力求侧滑角，并计龙骨诱导阻力 |
| 船体阻力 | 同上 | ITTC-57 摩擦阻力 + Cr(Froude 数) 查表剩余阻力，排水/滑行型按船型混合 |
| VPP | `src/vpp/vpp.ts` | 对分求平衡航速（推力=阻力），网格+细分搜索最优调帆，扫描极曲线 |

### 五个级别船型（`src/physics/boat-specs.ts`）

激光级 ILCA 7（单人稳向板）、470（双人竞赛小艇）、J/80（龙骨巡航船）、
Class40（离岸赛船）、Weta 4.4（三体船）。每个船型的扶正力臂、帆面积、阻力
特性、横倾上限等参数独立标定。

## 四个页面

- **航行页**：Canvas 动态海面、风粒子、带横倾/侧滑/鼓起帆形的帆船；实时仪表（航速、横倾、侧滑、视风）；键盘/滑杆操纵。
- **调帆页**：主帆/前帆独立的展开比例与调帆角，Cl/Cd 随攻角曲线和当前工作点，一键 VPP 最优调帆。
- **极曲线页**：多风速 VPP 扫描，极坐标曲线叠加设计参考极曲线（虚线），逐点误差表与 VMG 最优风角。
- **船型页**：五种级别卡片、完整物理参数表、Canvas 船型侧视示意。

## 命令

```bash
npm install
npm run dev       # 开发服务器
npm run build     # 类型检查 + 生产构建
npm test          # 22 个单元测试
npm run validate  # 极曲线对参考数据校验（验收：每船平均误差 <8%）
npm run bench     # 单帧物理与极曲线扫描性能基准
```

## 验收结果

`npm run validate`：五艘船平均绝对误差 4.0%~8.0%，全局 6.58%，PASS。
`npm run bench`：单帧 `evaluateAeroHydro` P95 ≤ 17 μs（约束 1000 μs），PASS。

## 键盘操纵（航行页）

| 键 | 作用 |
| --- | --- |
| ← / → 或 A / D | 左右舵 |
| W / S | 收帆 / 放帆 |
| Q / E | 真风角减小 / 增大 |
